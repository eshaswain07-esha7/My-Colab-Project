>Clinic Patient Admissions Analysis
An exploratory data analysis of clinic patient records from December 2025 to January 2026, built with Python.

>Key Findings

📅 Busiest days: Jan 2nd & Jan 22nd (2 patients each)
👨‍⚕️ Most active doctor: Dr. Robert Chen (3 patients in Jan 2026)
📈 Workload increase: Dr. Alan Patel & Dr. Robert Chen (Dec → Jan)

>Tools Used
Python | Pandas | Matplotlib | Google Colab

>How to Run
-Clone the repo

-Upload clinic dataset.xlsx when prompted
